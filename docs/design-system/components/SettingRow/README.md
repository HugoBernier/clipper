# SettingRow

A setting: its name left, its control right, rows split by `line` hairlines inside a `surface-1` panel.

- Name: one or two words. No help line.
- An error replaces nothing: it appears under the name in `rec-text` `caption`, a few words, no final period.
- Raccourci: Kbd + Modifier; while capturing, "Appuyez sur la combinaison" and Échap.
- Taille estimée: "≈ 17 Mo" in `heading`, resolution and bitrate in `caption` below.
