# Logos

- `clipper.svg`: the app icon from 32px up (exe, installer, title bar, Start menu). Tile in `tile`, outer ring in `tile-deep`, replay arrow in `tile-ink`, record dot in `rec`. One centre; the ring's and the arrow's openings sit on the same 225° diagonal; the arrowhead is built on the arc's tangent and points back (replay).
- `clipper-small.svg`: the same icon for 16–24px (tray, small lists): no outer ring, thicker arrow, bigger dot, so it stays readable.
- Full colour only, on any surface. Never redraw, recolour or rotate them; never add the name inside the tile.
